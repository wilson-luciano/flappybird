# Sprint 01 — Primeira interface

**Projeto:** Flappy Bird — Python e Pygame  
**Disciplina:** Programação para Engenharia Mecânica — UFS/DMEC  
**Aulas relacionadas:** 01.0 e 01.1  
**Etapa:** planejamento

## 1. Objetivo
Construir a janela e o loop principal do jogo.

## 2. Pré-requisitos
Sprint 00 concluída e validada.

## 3. Tarefas de desenvolvimento
- [ ] Criar src/main.py
- [ ] Inicializar pygame e janela 575 × 860
- [ ] Criar loop de eventos e tratar pygame.QUIT
- [ ] Controlar a taxa máxima de quadros com Clock.tick(30)
- [ ] Encerrar com pygame.quit()
- [ ] Executar pelo terminal do .venv
- [ ] Registrar alteração em commit Git

## 4. Critérios de aceitação
- [ ] Janela abre com 575 × 860 pixels
- [ ] Loop responde ao botão de fechar
- [ ] Programa encerra sem travar
- [ ] Execução ocorre pelo terminal do ambiente virtual

## 5. Evidências de conclusão
- Captura da janela em execução
- Código do loop principal e resultado do teste de fechamento

## 6. Procedimento de validação
1. Execute o projeto com o ambiente virtual ativado.
2. Verifique cada critério de aceitação e registre o resultado.
3. Corrija falhas antes de iniciar a próxima sprint.
4. Registre as alterações no Git com mensagem descritiva.

## 7. Observações didáticas
- FPS limita a taxa de quadros, não assegura um intervalo exato.
