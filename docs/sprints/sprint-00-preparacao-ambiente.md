# Sprint 00 — Preparação do ambiente

**Projeto:** Flappy Bird — Python e Pygame  
**Disciplina:** Programação para Engenharia Mecânica — UFS/DMEC  
**Aulas relacionadas:** 01.0 e 01.1  
**Etapa:** planejamento

## 1. Objetivo
Preparar uma instalação reproduzível do projeto.

## 2. Pré-requisitos
Estrutura do projeto disponível e Aula 01.1 iniciada.

## 3. Tarefas de desenvolvimento
- [ ] Conferir a pasta C:\Projetos\flappybird e sua estrutura
- [ ] Verificar Python 3.12.10 com py -3.12 --version
- [ ] Criar .venv com py -3.12 -m venv .venv e ativá-lo
- [ ] Atualizar somente pip e instalar pygame
- [ ] Selecionar .venv no VS Code
- [ ] Verificar README.md, requirements.txt e .gitignore
- [ ] Conferir que .venv/ e arquivos temporários não serão versionados

## 4. Critérios de aceitação
- [ ] Pasta do projeto criada e organizada
- [ ] .venv ativado e Pygame importável
- [ ] Interpretador do VS Code selecionado corretamente
- [ ] .gitignore evita versionar .venv e arquivos temporários
- [ ] README.md e requirements.txt presentes

## 5. Evidências de conclusão
- Captura do terminal com python --version e python -m pip show pygame
- Saída de git status sem .venv (após iniciar o repositório)

## 6. Procedimento de validação
1. Execute o projeto com o ambiente virtual ativado.
2. Verifique cada critério de aceitação e registre o resultado.
3. Corrija falhas antes de iniciar a próxima sprint.
4. Registre as alterações no Git com mensagem descritiva.

## 7. Observações didáticas
- A instalação global de Pygame não substitui a instalação dentro de .venv.
