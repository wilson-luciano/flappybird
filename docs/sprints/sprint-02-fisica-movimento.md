# Sprint 02 — Física, movimento e controles

**Projeto:** Flappy Bird — Python e Pygame  
**Disciplina:** Programação para Engenharia Mecânica — UFS/DMEC  
**Aulas relacionadas:** 02.0 e 02.1  
**Etapa:** planejamento

## 1. Objetivo
Implementar o movimento controlado do pássaro usando um modelo discreto simplificado.

## 2. Pré-requisitos
Sprint 01 concluída e validada.

## 3. Tarefas de desenvolvimento
- [ ] Criar componente/classe Passaro com estado de posição e velocidade
- [ ] Aplicar gravidade a cada atualização
- [ ] Implementar salto com tecla Espaço
- [ ] Estabelecer limites verticais e comportamento ao atingir o solo
- [ ] Separar atualização da física e desenho
- [ ] Adicionar animação do pássaro quando os recursos estiverem disponíveis
- [ ] Versionar a sprint

## 4. Critérios de aceitação
- [ ] Pássaro responde ao Espaço sem bloquear o loop
- [ ] Sem comando de salto, o pássaro acelera para baixo
- [ ] O estado é atualizado em cada quadro e os limites são tratados
- [ ] A lógica de movimento é identificável e comentada

## 5. Evidências de conclusão
- Vídeo curto ou sequência de capturas do salto
- Explicação da atualização de velocidade e posição

## 6. Procedimento de validação
1. Execute o projeto com o ambiente virtual ativado.
2. Verifique cada critério de aceitação e registre o resultado.
3. Corrija falhas antes de iniciar a próxima sprint.
4. Registre as alterações no Git com mensagem descritiva.

## 7. Observações didáticas
- Os valores de gravidade e salto são parâmetros por quadro; não devem ser apresentados como unidades SI sem conversão.
