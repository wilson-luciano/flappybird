# Sprint 03 — Obstáculos, colisões e pontuação

**Projeto:** Flappy Bird — Python e Pygame  
**Disciplina:** Programação para Engenharia Mecânica — UFS/DMEC  
**Aulas relacionadas:** 03.0 e 03.1  
**Etapa:** planejamento

## 1. Objetivo
Produzir uma versão jogável com obstáculos e regras de pontuação.

## 2. Pré-requisitos
Sprint 02 concluída e validada.

## 3. Tarefas de desenvolvimento
- [ ] Criar classe/componente Cano
- [ ] Gerar pares de canos com abertura controlada
- [ ] Mover obstáculos e remover os que saem da tela
- [ ] Detectar colisão com canos e limites
- [ ] Incrementar pontuação apenas uma vez por obstáculo superado
- [ ] Implementar estados de início, partida e fim
- [ ] Permitir reiniciar após o encerramento
- [ ] Versionar a sprint

## 4. Critérios de aceitação
- [ ] Canos se deslocam continuamente e novas passagens surgem
- [ ] Colisão provoca a consequência definida nas regras
- [ ] Pontuação aumenta uma vez por passagem válida
- [ ] Partida pode terminar e ser reiniciada sem travar

## 5. Evidências de conclusão
- Demonstração de pontuação e colisão
- Explicação de como se evita pontuação duplicada

## 6. Procedimento de validação
1. Execute o projeto com o ambiente virtual ativado.
2. Verifique cada critério de aceitação e registre o resultado.
3. Corrija falhas antes de iniciar a próxima sprint.
4. Registre as alterações no Git com mensagem descritiva.

## 7. Observações didáticas
- Definir antecipadamente se colisão reduz vida ou encerra imediatamente a partida.
