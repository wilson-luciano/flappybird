# Sprint 04 — Recursos avançados

**Projeto:** Flappy Bird — Python e Pygame  
**Disciplina:** Programação para Engenharia Mecânica — UFS/DMEC  
**Aulas relacionadas:** 04.0 e 04.1  
**Etapa:** planejamento

## 1. Objetivo
Acrescentar recursos de experiência de uso e personalização.

## 2. Pré-requisitos
Sprint 03 concluída e validada.

## 3. Tarefas de desenvolvimento
- [ ] Implementar contador de vidas e apresentação de estado
- [ ] Adicionar pausa e retomada
- [ ] Adicionar opção de habilitar/desabilitar som
- [ ] Integrar efeitos sonoros e recursos gráficos autorizados
- [ ] Salvar e recuperar recorde em arquivo
- [ ] Adicionar variação de cenário ou dificuldade
- [ ] Testar ausência de arquivo de recorde e recursos opcionais
- [ ] Versionar a sprint

## 4. Critérios de aceitação
- [ ] Vidas são atualizadas de acordo com as colisões
- [ ] Pausa interrompe atualizações da partida e retomada funciona
- [ ] Som pode ser habilitado ou desabilitado
- [ ] Recorde persiste entre execuções
- [ ] Ao menos uma personalização funciona e não impede jogar

## 5. Evidências de conclusão
- Capturas de pausa, vidas e recorde
- Registro do recurso adicional escolhido

## 6. Procedimento de validação
1. Execute o projeto com o ambiente virtual ativado.
2. Verifique cada critério de aceitação e registre o resultado.
3. Corrija falhas antes de iniciar a próxima sprint.
4. Registre as alterações no Git com mensagem descritiva.

## 7. Observações didáticas
- Recursos de terceiros exigem conferência de licença antes da publicação pública.
