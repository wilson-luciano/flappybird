# Flappy Bird — Projeto 2 | Programação para Engenharia Mecânica

Projeto avaliativo com Python e Pygame, desenvolvido incrementalmente nas Aulas 01 a 04.

## Como começar
1. Comece por `aulas/aula-00.0-obtencao-projeto-github.md` para baixar e organizar o material.
2. Leia `aulas/aula-01.0-planejamento-ambiente.md`.
3. Siga `aulas/aula-01.1-roteiro-pratico.md`.
4. Crie/ative `.venv`, instale as dependências e execute `python src/main.py`.

## Roadmap
- Aula 01: ambiente e primeira janela
- Aula 02: física e controles
- Aula 03: obstáculos e colisões
- Aula 04: recursos, testes e publicação

## Avaliação
Rubrica completa na Aula 01.0. Total de 10,0 pontos.
